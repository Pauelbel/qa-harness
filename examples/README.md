# Примеры

Запускаемые тесты, на которых проще всего учиться. Они работают без внешних систем:
HTTP-запросы идут на маленький сервер, который поднимается на время запуска.

```powershell
python -m pytest examples
```

Читайте по порядку: каждый следующий пример чуть сложнее предыдущего.

| № | Файл | Чему научитесь |
| --- | --- | --- |
| 1 | [test_01_http.py](test_01_http.py) | отправить запрос и проверить ответ; свой клиент поверх `BaseHttpClient` |
| 2 | [test_02_odata.py](test_02_odata.py) | проверить структуру и фильтр ответа OData |
| 3 | [test_03_excel.py](test_03_excel.py) | скачать Excel-отчёт и проверить колонки и значения; как выглядит сообщение об ошибках |
| 4 | [test_04_config_secrets_plugin.py](test_04_config_secrets_plugin.py) | читать секреты, настройки из `config.yaml` и подключить свой плагин |
| 5 | [test_05_preconditions.py](test_05_preconditions.py) | создать данные до теста и удалить после (фикстуры, фабрика) |
| 6 | [test_06_ui_login.py](test_06_ui_login.py) | тест в браузере: войти один раз, локаторы прямо в тестах |
| 7 | [test_07_postgres_and_browser.py](test_07_postgres_and_browser.py) | запрос к PostgreSQL и простой тест в браузере |

Служебные файлы (читать необязательно):

- [conftest.py](conftest.py): подключение плагинов и демо-сервер. Здесь же видно, как плагины подключаются списком.
- [demo_plugin.py](demo_plugin.py): пример собственного плагина со своей секцией настроек.

## Что пропускается и почему

- Примеры с **браузером** (файл 6 и часть файла 7) запускаются, когда установлен Chromium
  и задана переменная `EXAMPLE_UI=1`:

  ```powershell
  python -m playwright install chromium
  $env:EXAMPLE_UI='1'; python -m pytest examples
  ```

- Пример с **PostgreSQL** (файл 7) ждёт переменные окружения `EXAMPLE_PG_HOST`,
  `EXAMPLE_PG_DB`, `EXAMPLE_PG_USER`, `EXAMPLE_PG_PASSWORD`.

Пропущенные тесты (`skipped`) — это не ошибка.

## Как использовать пример для своего теста

Скопируйте нужный файл в `tests/` своего проекта, замените адрес и данные на свои и
удалите лишнее. Ничего из `conftest.py` в этой папке копировать не нужно: в своём
проекте его создаст команда `qa-core init`.
