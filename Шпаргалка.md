# qa-core: краткая шпаргалка

Здесь показаны только публичные компоненты ядра. Проектные URL, авторизация,
payload и бизнес-правила подставляются в репозитории конкретной системы.

## Backend-тесты

Установка backend-зависимостей:

```powershell
python -m pip install -e ".[backend]"
```

## HTTP

```python
import allure

from qa_core.clients.http import BaseHttpClient


@allure.epic("Backend")
@allure.title("Получение списка объектов")
def test_get_items() -> None:
    with allure.step("Отправить GET-запрос"):
        with BaseHttpClient() as http:
            response = http.get("https://service.example/api/items", timeout=10)

    with allure.step("Проверить статус и прочитать ответ"):
        response.raise_for_status()
        items = response.json()

    with allure.step("Проверить, что список не пуст"):
        assert items
```

По умолчанию клиент читает секцию `http` из корневого `config.yaml`. Другой файл
можно указать через `BaseHttpClient(config_path="configs/test.yaml")`.

## PostgreSQL

```python
import allure

from qa_core.clients.postgres import PostgresClient


@allure.epic("Backend")
@allure.title("Проверка новых заказов в PostgreSQL")
def test_new_orders_exist() -> None:
    with allure.step("Подключиться к PostgreSQL"):
        db = PostgresClient(
            dbname="app",
            user="tester",
            password="secret",
            host="db.example",
        )

    with allure.step("Получить новые заказы"):
        rows = db.fetch_all(
            "SELECT id FROM orders WHERE status = %s",
            ["new"],
        )

    with allure.step("Проверить, что заказы найдены"):
        assert rows
```

## Excel-checker

`ExcelSource` подготавливает файл, а checker только проверяет его. Тест собирает
оба кубика:

```python
from pathlib import Path

import allure

from qa_core.checks.excel import ExcelDataQualityChecker
from qa_core.sources.excel import ExcelSource


@allure.epic("Backend")
@allure.title("Проверка Excel-отчёта")
def test_report(report_api, tmp_path: Path) -> None:
    with allure.step("Получить отчёт"):
        response = report_api.download_report()
        report = ExcelSource.from_response(
            response,
            tmp_path / "report.xlsx",
        )

    with allure.step("Проверить структуру"):
        checker = ExcelDataQualityChecker(report.path)
        row_count = checker.get_row_count()
        checker.check_filename(
            actual_name=report.original_filename,
            expected_suffix=".xlsx",
        )
        checker.check_columns(["ФИО", "Дата"], strict_order=True)

    with allure.step("Проверить значения"):
        checker.check_required(["ФИО", "Дата"])
        checker.check_date("Дата")

    with allure.step("Завершить проверку отчёта"):
        checker.assert_valid()
```

Если файл уже лежит на диске, HTTP-клиент не нужен:

```python
report = ExcelSource.from_path("reports/report.xlsx")
checker = ExcelDataQualityChecker(report.path)
```

`report_api` остаётся в проекте, потому что знает конкретный URL и авторизацию.
`ExcelSource` в ядре знает только, как превратить полученное содержимое в файл.

## OData

```python
import allure

from qa_core.checks.odata import OdataAssertions


@allure.epic("Backend")
@allure.title("Проверка OData-ответа")
def test_odata_response(response) -> None:
    with allure.step("Прочитать OData-ответ"):
        payload = response.json()
        items = payload["value"]

    with allure.step("Проверить структуру и фильтр"):
        OdataAssertions.response_not_empty(items)
        OdataAssertions.top_limit(items, 10)
        OdataAssertions.filter_eq(items, "status", "new")
```

## Allure-плагин

В проектном `conftest.py`:

```python
pytest_plugins = ["qa_core.pytest_plugins.allure_reporting"]
```

Запуск с результатами и именем окружения:

```powershell
python -m pytest --alluredir=allure-results --qa-environment=test
```

Плагин приложит логи к упавшему тесту. Декораторы `epic`, `feature`, `story`,
`title` и шаги `allure.step` остаются в проектных тестах, потому что описывают
их бизнес-смысл.

## Frontend-тесты

Сначала установите Python-зависимости frontend-тестов:

```powershell
python -m pip install -e ".[frontend]"
```

Затем отдельно установите браузер Chromium:

```powershell
python -m playwright install chromium
```

В `conftest.py` проекта:

```python
pytest_plugins = [
    "qa_core.pytest_plugins.allure_reporting",
    "qa_core.pytest_plugins.playwright",
]
```

В тесте уже доступна готовая страница:

```python
import allure
from playwright.sync_api import Page


@allure.epic("Frontend")
@allure.title("Проверка главной страницы")
def test_home_page(browser_page: Page) -> None:
    with allure.step("Открыть главную страницу"):
        browser_page.goto("https://service.example")

    with allure.step("Проверить заголовок"):
        assert browser_page.title() == "Service"
```
